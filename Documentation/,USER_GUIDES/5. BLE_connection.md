# BLE connection

(c) 2025-2026, Edo. Franzi, 2026-05-12



All targets equipped with an Espressif Systems **ESP32** module are fully integrated into the **µKOS-X** operating system.

The operating system can:

- Provide a dedicated **ble0 console**, allowing interactive remote access over **BLE**.
- Use the **BLE** channel as an output device for standard diagnostic messages generated with `dprintf()`.

This feature is particularly useful for embedded systems that do not have a direct serial connection or when remote debugging is preferred.

## Overview

The **BLE** interface allows a host computer or mobile device to communicate wirelessly with the target through a custom **BLE** service.

Typical use cases include:

- Opening a remote system console (`console ble0`)
- Redirecting debug traces and logs
- Monitoring system activity without a physical UART connection

Please refer to the ESP32 firmware located in the following directory:

```bash
cd ${PATH_UKOS_X_PACKAGE}/Third_Parties/esp32/Construction/Interface/ble_to_uart
```

Unlike Wi-Fi communication, **BLE** does **not** rely on IP networking and does not use TCP or UDP sockets. Data is exchanged through **BLE** characteristics using notifications and write operations.

## Initial Setup

Before using the **BLE** console or redirecting output, the **ESP32** module must be reset and initialised.

### Commands from a Conventional Console (`urt0`)

```bash
# From a conventional console (i.e. urt0)
# Initialise and start the BLE service
esp32 -reset
esp32 -ble "Name"
```

### Expected Output

```bash
Control of the ESP32 chip.
Waiting for the connection ...
BLE ready
```

Once initialised, the target begins advertising and becomes visible to nearby BLE-capable devices.

### Connecting from a Host Computer (i.e. iPhone)

A BLE client application is required to connect to the target. Suitable tools include:

- Bluetoothctl (Linux)
- [nRF Connect for Desktop](https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-Desktop?utm_source=chatgpt.com)
- [nRF Connect for Mobile](https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-mobile?utm_source=chatgpt.com)

After connection, the host can exchange data with the console service through the designated **BLE** characteristics.

### Usage as a µKOS-X console

```bash
# From a conventional console (i.e. urt0)
# Launch a ble0 console
console ble0
```

This command launches a console session over the **BLE** interface.

### Redirect the dprintf to the ble0 manager

```bash
dprintf(KBLE0, "System started successfully.\n");
```

## Typical Workflow

1. Reset the ESP32 module.
1. Start the BLE service with `esp32 -ble`.
1. Connect to the target using a BLE client.
1. Launch the `ble0` console or redirect output with `dprintf()`.

### Example Session

```bash
# On the target console
esp32 -reset
esp32 -ble "Name"
console ble0
```

```c
// In application code

dprintf(KBLE0, "Temperature = %d°C\n", temperature);
```

## Summary

**µKOS-X** provides native integration of **ESP32-based Bluetooth Low Energy communication**. The `ble0` interface can be used either as a complete wireless console or as a transport for diagnostic messages, enabling convenient cable-free interaction with embedded targets.
