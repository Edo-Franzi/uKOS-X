# WIFI connection

(c) 2025-2026, Edo. Franzi, 2026-05-12



All targets equipped with an Espressif Systems **ESP32** module are fully integrated into the **µKOS-X** operating system.

The operating system can:

- Provide a dedicated **wfi0 console**, allowing interactive remote access over **Wi-Fi**.
- Use the **Wi-Fi** channel as an output device for standard diagnostic messages generated with `dprintf()`.

This feature is particularly useful for embedded systems that do not have a direct serial connection or when remote debugging is preferred.

## Overview

The **Wi-Fi** connection mechanism is based on the **ESP32** network interface. Once the target is connected to a wireless network, **µKOS-X** opens a TCP server (by default on port `3333`) that can be accessed from any host on the same network.

Typical use cases include:

- Opening a remote system console (`console wfi0`)
- Redirecting debug traces and logs
- Monitoring system activity without a physical UART connection

Please refer to the ESP32 firmware located in the following directory:

```bash
cd ${PATH_UKOS_X_PACKAGE}/Third_Parties/esp32/Construction/Interface/wifi_to_uart
```

## Initial Setup

Before using the **Wi-Fi** console or redirecting output, the **ESP32** module must be reset and connected to a wireless network.

### Commands from a Conventional Console (`urt0`)

```bash
# From a conventional console (i.e. urt0)
# Initialise and connect the target to a WI-FI network
esp32 -reset
esp32 -wifi "Netwok_Name" "Password"
```

### Expected Output

```bash
Control of the ESP32 chip.
Waiting for the connection ...
192.168.1.143:3333
```

When the connection is established, the system displays:

- The IP address assigned to the target (`192.168.1.143`)
- The TCP port used by the **µKOS-X Wi-Fi server** (`3333`)

### Connecting from a Unix Terminal

On any Unix/Linux/macOS host connected to the same network, use **Netcat** `nc` (`netcat`) to open a TCP connection to the target:

```bash
nc 192.168.1.143 3333
```

Once connected, the terminal becomes linked to the **µKOS-X Wi-Fi** channel.

### Usage as a µKOS-X console

```bash
# From a conventional console (i.e. urt0)
# Launch a wfi0 console
console wfi0
```

This command launches a console session over the **Wi-Fi** interface. All console input and output are then transmitted through the TCP connection.

### Redirect the dprintf to the wfi0 manager

```bash
dprintf(KWFI0, "System started successfully.\n");
```

## Typical Workflow

1. Reset the **ESP32** module.
2. Connect the target to a Wi-Fi network.
3. Note the IP address displayed by the system.
4. Open a TCP connection using `nc`.
5. Launch the `wfi0` console or redirect output with `dprintf()`.

### Example Session

```bash
# On the target console
esp32 -reset
esp32 -wifi "Netwok_Name" "Password"
console wfi0
```

```bash
# On the host computer
nc 192.168.1.143 3333
```

```c
// In application code

dprintf(KWFI0, "Temperature = %d°C\n", temperature);
```

## Summary

**µKOS-X** provides seamless integration of **ESP32-based Wi-Fi connectivity**. The `wfi0` interface can be used either as a full remote console or as a transport for debug messages, enabling convenient wireless interaction with embedded targets.
